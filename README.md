# 风和日丽 · fhrl.life

静态网站：`/` 为首页，`/journote/` 为己之言介绍，`/journote/privacy/` 为隐私政策，`/journote/support/` 为支持页面。无需依赖或构建步骤。

本地预览：`python3 -m http.server 8000`，访问 `http://localhost:8000/`。部署时将本目录作为站点根目录，并让服务器支持目录索引（`index.html`），将 `/journote` 和 `/journote/privacy` 重定向到带尾斜杠的目录路径。

上线前请确认隐私政策与实际发布版本、第三方服务及运营主体一致，补充可公开的联系渠道和政策日期。ICP备案取得后在首页底部中央显示真实备案号，并链接到 https://beian.miit.gov.cn/；请遵循接入商和当地主管部门要求。域名、HTTPS、接入商及备案需另行配置。

## 己之言 · flomo 参考方向

分支：`design/journote-flomo`。以绿色主色、清晰留白、日记手机示意和交替图文介绍己之言。包含示例记录切换、照片翻面、示例搜索、常见问题和移动导航。

所有功能演示仅使用本页示意记录；搜索在浏览器中完成。没有登录、数据上传或新增依赖。隐私政策和支持页面使用一致的样式。

在此工作目录执行 `python3 -m http.server 8782 --bind 127.0.0.1`，打开 `http://127.0.0.1:8782/journote/`。当前分支不合并到 main；选定方向后可再整合和部署。
